# 千夜浮梦 · 小剧场生成器

一个用于 **独立生成小剧场、长篇续写与作品收藏** 的 SillyTavern 扩展。

看到好玩的小剧场指令，想让角色演一场番外，又不想暂停正文、把生成结果删掉？千夜浮梦把小剧场放进独立面板：按需读取角色、世界书和聊天前文，生成后可以阅读、保存、续写，也可以让故事拥有自己的 HTML 排版与互动。

插件由禾禾与小克、g 老师一起制作。感谢染染提供的轻量小剧场预设。

## 先选一种玩法

| 想做什么 | 从哪里开始 |
| --- | --- |
| 写一篇番外、日常片段，试试新指令 | 在「生成」页输入小剧场指令 |
| 接着一篇结果往下写，比较本段的不同版本 | 打开结果操作中的「续写」 |
| 把故事写成多章长篇，管理设定、记忆和章节 | 在「长梦」页选一篇作为第一章 |
| 找回、整理或带走已经保存的作品 | 打开「历史」；长梦在自己的作品页管理 |

**小剧场生成不会向聊天正文追加楼层。** 普通生成按所选素材取用前情；长梦按自己的章节、定梦与梦脉续写，不直接读取聊天楼层作为续章前情。

## 安装与第一次生成

1. 打开酒馆的扩展管理，选择「安装扩展」。
2. 输入仓库地址：`https://github.com/koichole213-ui/st-theater`，按页面选项安装；需要所有用户使用时可选择 `Install for all users`。
3. 点击对话输入框左侧的魔法棒，再点击「小剧场」打开插件。也可以在设置中开启悬浮球。
4. 在「设置」页配置生成线路：推荐独立 API，填写服务地址、Key、模型与协议，保存设置；也可选择酒馆主 API（实验）。连接检测会访问所选服务。
5. 在「设定」页选择生成预设和世界书；在「对话」页设置 User 人设及聊天前文条数。条数设为 `0` 时不读取聊天前文。
6. 在「规则」页选择渲染模板。想先看文字可以选纯文字模板；想要丰富排版，可以选内置 HTML 或剧情自适应模板，并按需开启交互模式。
7. 回到「生成」页输入指令，点击「生成」。例如：

   > 写一篇角色们雨天一起吃火锅的番外，约 2000 字，侧重对话和轻松的生活细节。

8. 生成后展开结果旁的「操作」，可以保存、复制文字、全屏阅读、续写或编辑文字。喜欢的作品请主动保存到历史，再定期导出备份。

首次使用可以先完成一篇小剧场，再按需要尝试续写和长梦。生成会调用所选 API，时间与费用取决于服务和模型。

## 小剧场与普通续写

- **独立创作：** 选择酒馆创作预设、角色和 User 人设，按需读取多本世界书与聊天前文；创作预设可单独选择，不必跟正文使用同一套。
- **目标字数：** 识别指令中的明确字数，也可以开启「独立目标」手动设置；开启后以手动目标为准。
- **普通续写：** 从前文末尾接写，旧正文不计入本次新增目标；可以切换本段版本、重写本段，选好后再接下一段。
- **模板管理：** 常用指令可存为模板，支持标签、搜索、批量管理与导入／导出，也可以从指定范围随机抽取。
- **最近结果：** 当前结果单独保留，另外留存最近三条此前生成的结果，便于切换查看；继续生成会轮换最近结果，重要作品仍需主动保存。

### 字数与自动补写怎么理解？

普通生成和普通续写的规则是：

- **目标低于 5000 字：** 即使开启自动补写，也只生成一轮。
- **目标达到 5000 字：** 开启自动补写后，可在设定的总轮数上限内分轮完成正文。界面里的「最多补写轮数」包含首轮，不是首轮之外再追加这么多轮。
- **关闭自动补写：** 正文只生成一轮，较大的目标也不会自动追加正文请求。
- **长篇 HTML：** 普通新生成的目标达到 5000 字时，先写正文，再单独请求统一排版；普通续写如果只生成一轮，沿用单轮排版方式，实际发生多轮补写后再统一排版。因此正文一轮不等于整个过程只有一次 API 请求。纯文字模板由插件本地显示。

自动补写使用目标字数的九成作为长度判断线，仍受轮数上限和请求结果约束。目标字数是给模型的写作要求，实际输出可能不足；输出 Token 上限也不是必定写出的字数。分轮补写和独立排版会增加耗时与 API 用量。

## 长梦：把一篇故事续成一卷

从当前结果、最近生成或历史作品里选一篇作为第一章，给这场梦起名，再填写下一章想看的剧情。每章独立保存，后续可以回看、导出，也可以另开支线。

### 定梦：这场故事必须遵守的设定

填写人物、关系、背景和不可改变的事实，选择故事与原世界的关系：完全隔离、平行支线／AU、前传、原线同期或正史后续。创建时可以选择世界书作为此梦的资料快照。

也可以请 AI 根据所选第一章整理定梦建议，再由自己修改、挑选并确认。建议只是待确认草稿，不会自动成为正式设定。

### 梦脉：跟随章节积累的故事记忆

梦脉整理人物状态、关系变化、伏笔约定与世界线变化，续章时结合近期章节和相关记忆提供前情。记错的内容可以手动修改；出现冲突时，可以查看原梦脉与本章新变化，再决定如何处理。

在「设置 → 梦脉织录」绑定副 API 预设后，确认的章节会加入待整理队列，默认累计三章后后台批量整理，也可调整批量。未绑定时暂停自动织录。梦脉整理是单独的 API 请求，会产生额外用量。

支持手动更新概要、查看最近五版概要以及恢复符合条件的旧版。恢复有保护条件，并非每个旧版都能恢复；按钮不可用时，先查看页面显示的原因。手动更新与恢复需要二次确认。

### 候选：先挑选，再收入长卷

- 新章生成后先进入待确认区，可以比较版本或再生成。
- 未标记保留的候选轮换保存最近三版；主动「保留」的候选不会被轮换挤掉，可以再次取消保留。
- 点击「用这版继续」后，采用版保存为正式章节，其他保留版也随该章收录；随后回到续写页，**不会自动生成下一章**。
- 后续写作和梦脉使用采用版；其他保留版可阅读、导出和随备份恢复。
- 支持从某章另开支线，也可以保留原卷重写章节。保留候选本身不会自动创建支线。

长梦开启自动补写后，不受普通生成的 5000 字门槛限制：不足目标九成时，可以在设定轮数内继续正文，再进行排版。字数和故事连贯性仍需自己检查。

## 阅读、互动与整理

- **排版与互动：** 内置手机版／PC 版轻量 HTML、剧情自适应模板，以及亮色／暗色夜读纯文字模板；支持自定义渲染规则、交互要求和常用 A／B 模板切换。实际互动效果取决于模型输出。
- **全屏阅读与改字：** 支持全屏阅读；普通静态 HTML 可在保留排版的前提下编辑文字。含互动脚本或特殊排版的作品可能不支持安全改字，页面会给出提示并保留原稿。
- **历史收藏：** 用标签、文件夹和系列整理作品，支持批量操作、单篇导出、批量 ZIP 导出，以及 ZIP／JSON 备份导入。
- **世界书：** 支持多本选择、树形条目、筛选与书内全选／全不选，可开启跟随角色卡；蓝灯／绿灯按酒馆原生规则判断，页面提供 Token 用量估算。
- **自动模式：** 按聊天累计 AI 回复楼层，到达设定数量后在后台生成；可以指定指令来源。自动模式会在满足条件时发出生成请求，请按需开启。
- **通知与外观：** 六种提示音、悬浮球小红点与贴边收纳；粉彩、跟随酒馆主题、自定义 CSS 三种面板外观。
- **线路与维护：** 保存多套独立 API 配置、获取模型列表、检测连接、查看诊断与脱敏运行日志，以及检查插件更新。

## 保存与备份，请先看这一段

**普通历史与长梦主要保存在当前浏览器、当前酒馆地址对应的本地数据库中。不是保存在插件文件夹里，也不会自动跨设备同步。**

- 清除这个站点的存储／网站数据，可能清空作品；普通网页缓存与站点存储不是同一项，清理浏览器时请确认选择了什么。
- 换浏览器、换设备，或换酒馆访问地址，可能看不到原来的本地存档；这不一定表示原存档已被删除。
- **普通历史和长梦需要分别导出备份。** 普通历史在「历史」页导出；长梦使用自己的整卷／作品库备份功能。
- 单篇阅读文件便于分享和阅读；需要完整迁移作品、候选与章节信息时，请使用对应的备份功能。
- 最近三条结果不是完整备份。重要作品先保存，清理数据或换设备前再导出，并确认文件已经下载。

## 遇到问题

先打开「诊断」页，查看当次请求结果与常见问题说明；需要反馈时，可导出诊断报告，并补充：

- 插件版本、酒馆版本、设备与浏览器。
- 从哪个页面进行了什么操作，预期是什么，实际发生了什么。
- 当次错误提示；字数问题附目标字数、实际字数、自动补写开关及轮数设置。

分享前再检查一次内容，不要公开 API Key、密码或其他私人信息。更新后如果表现没有变化，可以刷新酒馆，并在设置页底部确认版本。

## 兼容与许可

面向 SillyTavern 1.12.0+。独立 API 提供 OpenAI 兼容与 Anthropic 协议选项，酒馆主 API 路线为实验功能；具体可用性取决于酒馆版本、服务端协议、模型及浏览器环境，不保证所有线路均兼容。
