# 小剧场生成器 / Theater Generator

独立生成小剧场/番外内容的 SillyTavern 扩展插件。在插件面板中调用API生成HTML小剧场，不影响正文剧情。

## 功能

- **独立生成** — 小剧场在插件面板内独立生成，完全不影响正文
- **预设选择** — 从酒馆已导入的 Chat Completion 预设中选择，按条目开关，独立于正文预设
- **世界书切换** — 支持多本世界书与条目开关；蓝灯/绿灯由酒馆原生规则判断后再交给小剧场
- **流式传输** — 主API和独立API均支持SSE流式传输，实时显示生成内容
- **输出上限回落** — 单轮默认 16384 Token，低上限模型拒绝时自动降低后重试
- **目标字数系统** — 首轮明确篇幅并后台计数；5000 字起可把同一份稿件分成至少两轮纯正文补完，达到目标后再统一排版 HTML
- **API 预设** — 保存多套独立 API 配置，地址、协议、Key、模型和输出上限可一键切换
- **运行日志** — 内存保留最近 200 条分级日志，一键复制并统一脱敏
- **指令模板** — 保存常用指令并添加多个标签；旧分组会自动变成同名标签，JSON 备份可跨设备保留
- **聊天前文** — 可直接输入 0–500 条读取楼层数，支持填 0 完全不读取；模板与世界书条目适配手机窄屏
- **双模板快捷切换** — 在设置中任选 A/B 两个模板，从生成页标题左侧一按往返
- **剧情自适应排版** — 提供灵动、沉浸、实验三种内置模板；先完成正文，再按本篇物件、结构与情绪独立设计互动 HTML
- **渲染规则** — 基础内置、剧情自适应与用户自定义模板统一管理，记住上次选择
- **交互模式** — 普通模板可自由追加交互；剧情自适应模板由自身规则接管互动设计
- **历史记录** — 保存生成结果并按同一套标签整理，支持单条导出、批量 ZIP 导出，以及 ZIP / JSON 备份恢复
- **悬浮球** — 可选悬浮球快速打开面板，设置中开关
- **主题跟随** — 面板自动跟随酒馆主题配色
- **自定义CSS** — 自定义插件面板样式
- **安全更新** — 面板内更新扩展，不刷新页面不影响其他插件

## 安装

### 方法一：扩展管理器（推荐）

Extensions → Install Extension → 粘贴仓库地址

### 方法二：手动安装

将文件放入 `data/default-user/extensions/third-party/st-theater/`

## 面板结构

1. **生成** — 输入指令、流式输出、生成结果
2. **素材** — 生成预设、User人设、世界书、上下文条数
3. **规则** — 指令模板库、渲染规则模板
4. **历史** — 保存的小剧场、单条/批量导出、ZIP / JSON 备份恢复
5. **美化** — 自定义CSS
6. **设置** — API配置、扩展更新

## 兼容性

- SillyTavern 1.12.0+
- 支持所有 API
